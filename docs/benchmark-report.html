🎯 核心发现

  • sequence 三种存储模式 RPC 性能几乎一致（~370 ops/s 单线程）——workerId 只在启动时租约，运行时 ID 生成纯进程内（纳秒级），瓶颈在 HTTP 层不在存储
  • lock Redis 比 MySQL 快 2.5~6 倍——Redis P50=5.9ms vs MySQL P50=15.2ms（单线程）；32 线程时 Redis 568 ops/s vs MySQL 111 ops/s
  • async 内存模式比 MySQL 快 1.6~2.7 倍——跳过 DB INSERT，纯进程内队列
  • 进程内 vs RPC 层开销——ID 生成进程内 78ns → RPC 2.4ms（30,000×），瓶颈完全在 HTTP+Spring MVC+JSON 基础设施层
