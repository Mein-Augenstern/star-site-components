🎯 核心发现

  • sequence 三种存储模式性能几乎一致（~370 ops/s 单线程）——workerId 只在启动时租约，运行时 ID 生成纯进程内
  • lock Redis 比 MySQL 快 2.5~6 倍——Redis P50=5.9ms vs MySQL P50=15.2ms；32 线程时 568 vs 111 ops/s
  • async 内存模式比 MySQL 快 1.6~2.7 倍——跳过 DB INSERT，纯进程内队列
  • RPC vs 进程内：ID 生成 78ns → 2.4ms（30,000×）——瓶颈完全在 HTTP+JSON 基础设施层，组件自身开销可忽略
